# DevOps Modern End-to-End Deployment Final Project

## Project Overview
This repository contains a complete automated DevOps pipeline that deploys a containerized Portfolio Web Application and a Java Web Service onto an Amazon Web Services (AWS) infrastructure using Infrastructure as Code (IaC), configuration management, and CI/CD automation.

## Architecture & Tools Used
- **Infrastructure:** AWS (VPC, Subnet, Internet Gateway, Security Groups, EC2 instance)
- **Infrastructure as Code:** Terraform (Dynamic AMI lookup)
- **Configuration Management:** Ansible
- **Containerization:** Docker & Docker Compose
- **CI/CD Pipeline:** GitHub Actions
